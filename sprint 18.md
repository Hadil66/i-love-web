# Refactoring
## Clean code - Robert C. Martin 
Try to leave this world a little better than when you found it. ← same goes for code
- betekinsvolle namen gebruiken
- kleine functies moeten klein zijn en 1 verantwoordelijkheid hebben-> single responsibilty principle
- zo min mogelijk parameters
- gebruik goede comentaar; less is more
- maak je code leesbaar voor mensen ( code wordt meer gelezen dan geschreven )

## Refactoring - Martin Fowler
- proces van het verbeteren van het structtur van de code zonder heg gedrag te veranderen
- doel: leesbaarder, eenvoudiger te begrijpen, makkelijker onderhoudbaar, makkelijker uitbreidbaar
- hernoem functie declaratie
- split conditionals op
- vervang loops dor pipelines
- verwijder dode code
- verschuif statements
